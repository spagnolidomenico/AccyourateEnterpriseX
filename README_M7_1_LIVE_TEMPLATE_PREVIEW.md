# M7.1 — Live Template Preview

Questa release trasforma il Branding Center in un designer a due pannelli:

- configurazione azienda e template a sinistra;
- anteprima A4 sempre visibile a destra;
- aggiornamento automatico durante la modifica dei campi;
- indicatore LIVE;
- anteprima ridimensionata per restare leggibile senza comprimere il form;
- nessuna proprietà Avalonia non compatibile introdotta.

## Verifica

1. Aprire `Amministrazione → Branding Center`.
2. Modificare ragione sociale, indirizzo o colore principale.
3. Controllare che l'anteprima a destra si aggiorni senza aprire una scheda separata.
4. Cambiare modello intestazione, dimensione e posizione del logo.
5. Salvare e generare l'anteprima PDF.

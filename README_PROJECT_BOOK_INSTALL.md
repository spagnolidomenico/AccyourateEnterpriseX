# Come installare il Project Book nel repository

1. Estrai questo ZIP.
2. Copia le cartelle:
   - docs
   - roadmap
   - .github
3. Incollale nella cartella principale del repository `AccyourateEnterpriseX`.
4. Apri GitHub Desktop.
5. Verifica i file modificati.
6. Commit:

```text
Add Project Book v1.0
```

7. Push su GitHub.

# M5.1 — Asset Focus Layout

Questa patch rende la dashboard operativa comprimibile per restituire spazio verticale alla lista degli asset.

## Novità

- Dashboard operativa chiusa per impostazione iniziale.
- Pulsante `Mostra / Nascondi` per aprire i pannelli quando servono.
- KPI più compatti.
- Header e spaziature verticali ridotti.
- Lista asset sempre protagonista e visibile anche su schermi con altezza contenuta.
- I dati della dashboard continuano ad aggiornarsi anche quando la sezione è chiusa.

## Verifica

1. Aprire Asset Management.
2. Verificare che la lista sia immediatamente visibile.
3. Premere `Mostra ▼` nella barra Dashboard operativa.
4. Verificare i tre pannelli.
5. Premere `Nascondi ▲` e controllare che la lista recuperi spazio.

# UI Review Checklist

## Layout
- [ ] La schermata ha uno scopo chiaro.
- [ ] Le informazioni principali sono visibili.
- [ ] Margini e spaziature sono coerenti.

## Componenti
- [ ] Pulsanti coerenti.
- [ ] Card coerenti.
- [ ] KPI allineati.
- [ ] Badge coerenti.
- [ ] Tabelle leggibili.

## UX
- [ ] Azioni principali entro due clic.
- [ ] Stato vuoto utile.
- [ ] Errori comprensibili.
- [ ] Loading presente per operazioni lunghe.

## Qualità
- [ ] Build OK.
- [ ] Smoke test OK.
- [ ] Nessun nuovo warning critico.

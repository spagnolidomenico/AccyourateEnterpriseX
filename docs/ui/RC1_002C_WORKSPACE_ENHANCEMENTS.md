# RC1-002C - Workspace Enhancements

## Obiettivo

Rifinire il Workspace Enterprise migliorando la gestione delle schede, le azioni rapide e la status bar.

## Miglioramenti

- Apertura singola dei moduli tramite `WorkspaceTabManager.OpenOrActivate`.
- Nuovo comando `CloseOthers` nel tab manager.
- Pulsanti `Chiudi altre` e `Chiudi tutte` nel Workspace Host.
- Indicazione numero schede aperte.
- Empty state coerente tramite `AxEmptyState`.
- Sezione `Azioni Workspace` nel menu laterale.
- Status bar più orientata a Release Candidate.
- Pulizia del doppio controllo `OpenRegisteredWorkspaceModule` nella navigazione.

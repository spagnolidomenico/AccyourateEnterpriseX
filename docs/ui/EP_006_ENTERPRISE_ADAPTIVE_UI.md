# EP-006 - Enterprise Adaptive UI Framework

## Modifiche
- Breakpoint compatto a 1180 px logici.
- Master/detail affiancati su schermi ampi.
- Pannello dettagli sotto la tabella su schermi compatti o scaling elevato.
- Tabella con larghezza minima e scrollbar orizzontale.
- Filtri e azioni su righe separate.
- Pulsanti dettaglio su griglia 2x2.

## Test manuali
Verificare Asset Management a scaling Windows 100%, 125% e 150%.

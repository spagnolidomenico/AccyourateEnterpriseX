# 03 - UI/UX Guidelines

## Stile

- Enterprise moderno
- Ispirazione Apple / Fluent / Linear / SAP Fiori
- Pulito, leggibile, professionale
- Card arrotondate
- Ombre leggere
- Spaziature generose
- Icone coerenti

## Regole UI

- Evitare nuove finestre isolate se non necessarie
- Preferire moduli interni alla Workspace
- Usare componenti comuni
- Mantenere coerenza grafica
- Progettare per Full HD, 2K e 4K

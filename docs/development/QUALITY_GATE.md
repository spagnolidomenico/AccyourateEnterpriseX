# Quality Gate

Ogni sprint è chiuso solo quando tutti i punti seguenti sono rispettati.

## Build

- [ ] `test-smoke.ps1` superato
- [ ] nessun errore di compilazione
- [ ] warning nuovi valutati

## Funzionale

- [ ] funzionalità sprint testata
- [ ] regressione moduli principali
- [ ] eventuali bug documentati

## Documentazione

- [ ] README aggiornato se necessario
- [ ] CHANGELOG aggiornato
- [ ] PROJECT_STATUS aggiornato
- [ ] ADR aggiunto se decisione architetturale
- [ ] checklist test aggiornata

## Git

- [ ] commit con messaggio chiaro
- [ ] push origin
- [ ] branch corretto

## Decisione

- [ ] sprint validato
- [ ] sprint da correggere

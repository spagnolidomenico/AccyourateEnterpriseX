# Repository Structure

Struttura consigliata del repository:

```text
AccyourateEnterpriseX
│
├── .github
├── assets
├── docs
├── roadmap
├── scripts
├── src
├── tests
├── tools
├── installers
├── samples
├── README.md
├── CHANGELOG.md
└── AccyourateEnterpriseX.sln
```

## Cartelle

- `src`: codice sorgente.
- `docs`: Project Book e documentazione tecnica.
- `roadmap`: epiche, milestone, pianificazione.
- `scripts`: automazioni PowerShell.
- `.github`: template issue, PR, workflow build.
- `tests`: test futuri.
- `assets`: immagini, loghi, risorse.
- `tools`: strumenti interni.
- `installers`: setup e pacchetti futuri.
- `samples`: dati demo e scenari di test.

# UPDATE-001 - Update Center Foundation

Introduce il centro aggiornamenti della piattaforma.

Componenti:
- `VersionManifest`
- `ReleaseNote`
- `UpdateService`
- `UpdateCenterView`
- `UpdateWorkspaceModule`

Funzionalità:
- versione installata;
- canale aggiornamento;
- release notes locali;
- export manifest;
- verifica aggiornamenti simulata.

# Accyourate Enterprise X - Metodo di rilascio

Da questa versione il progetto viene gestito con tre canali.

## 1. Developer Edition

È la versione di sviluppo.

Contiene:
- codice sorgente;
- nuove funzionalità;
- test manuali;
- documentazione tecnica;
- eventuali funzioni ancora in fase di verifica.

Non va considerata una versione definitiva.

## 2. Release Candidate

È una versione candidata alla stabilità.

Una Developer Edition diventa RC solo se:
- compila senza errori;
- si avvia;
- login e database funzionano;
- le nuove funzioni superano la checklist;
- non rompe funzioni già validate.

## 3. Stable

È la versione approvata.

Una RC diventa Stable solo dopo collaudo completo.

La Stable va conservata come punto sicuro prima di ogni nuovo sviluppo.

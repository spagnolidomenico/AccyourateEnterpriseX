# Git Workflow consigliato

## Branch

```text
main        -> ultima stable
develop     -> sviluppo corrente
feature/*   -> nuove funzionalità
release/*   -> release candidate
hotfix/*     -> correzioni urgenti
```

## Tag

```text
v3.1.0-developer
v3.1.0-rc1
v3.1.0-stable
```

## Regola

Non sviluppare direttamente su `main`.

# Versioning

Accyourate Enterprise X userà questo schema:

```text
MAJOR.MINOR.PATCH-CANALE
```

Esempi:

```text
1.1.0-developer
1.1.0-rc1
1.1.0-stable
1.2.0-developer
```

## Regole

### MAJOR
Cambio architetturale importante.

### MINOR
Nuova funzionalità o nuovo modulo.

### PATCH
Correzione bug o miglioramento minore.

### CANALE
- developer
- rc
- stable

# 15.0.1A - Enterprise Home Framework

## Obiettivo

Sostituire la vecchia Workspace Home con una nuova Enterprise Home post-login.

## Componenti introdotti

- Welcome Panel.
- KPI principali.
- Quick Actions.
- Notifiche iniziali.
- Stato sistema.
- AI Welcome.
- Attività recenti.

## Cosa cambia

La voce `Home` della Workspace ora apre una dashboard operativa più professionale e orientata all'uso quotidiano.

## Cosa NON cambia

- Nessuna modifica database.
- Nessuna modifica login.
- Nessuna modifica Asset Management.
- Nessuna modifica Anagrafica Aziendale.
- Nessuna modifica permessi.

# Git & Release Flow

## Branch consigliati

```text
main
develop
feature/*
release/*
hotfix/*
```

## Regole

- `main` contiene solo versioni stabili.
- Ogni sprint usa un branch dedicato.
- Nessun commit se la build non passa.
- Ogni release deve avere changelog.

## Commit message

```text
AREA-000: Descrizione breve
```

# Accyourate Enterprise X - Developer Handbook

Questo handbook definisce le regole tecniche, architetturali e operative per sviluppare Accyourate Enterprise X come piattaforma enterprise modulare.

## Principi guida

1. La piattaforma viene prima dei moduli.
2. Ogni modulo deve essere indipendente.
3. I servizi condivisi vivono in `Platform`.
4. La UI deve seguire la Design Language.
5. Ogni modifica deve essere testabile.
6. Ogni sprint deve avere documentazione e checklist.
7. Nessun commit senza build verde.

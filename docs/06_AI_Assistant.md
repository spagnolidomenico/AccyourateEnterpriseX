# 06 - AI Assistant

## Stato attuale

- Enterprise AI Assistant Foundation
- Routing Engine
- Intent Catalog
- Catalog Manager
- Confidenza
- Termini riconosciuti
- Alternative

## Obiettivo

Trasformare l'AI Assistant in un copilota operativo.

## Capacità future

- ricerca dati aziendali
- apertura moduli
- filtro griglie
- creazione manutenzioni
- generazione report
- export Excel/PDF
- workflow guidati
- interrogazione Digital Twin
- analisi KPI

## Principio

L'AI non deve eseguire direttamente codice arbitrario. Dovrà invocare azioni registrate e autorizzate tramite Action Engine.

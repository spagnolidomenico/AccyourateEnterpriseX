# Quality Gate - Accyourate Enterprise X

Ogni sprint deve rispettare questi controlli minimi.

## Locale

- [ ] Smoke test PowerShell superato
- [ ] App avviata
- [ ] Test funzionale completato
- [ ] CHANGELOG aggiornato
- [ ] README aggiornato se necessario
- [ ] PROJECT_STATUS aggiornato se necessario

## GitHub

- [ ] Commit eseguito
- [ ] Push origin
- [ ] GitHub Actions build completata con successo

## Stato sprint

Uno sprint è considerato completato solo quando:

```text
Build locale ✅
Test funzionale ✅
GitHub Actions ✅
Commit/Push ✅
```

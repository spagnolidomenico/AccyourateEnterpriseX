# HR-002E - Employee Profile Foundation

## Obiettivo

Trasformare il dettaglio laterale del dipendente in una prima versione del profilo operativo HR.

## Funzionalità

La scheda dipendente ora mostra sezioni distinte:

- Anagrafica
- Organizzazione
- Contratto
- Asset assegnati
- Documenti
- Timeline
- Note

## Cosa cambia

Il dettaglio non è più solo un riepilogo semplice, ma diventa la base della futura scheda completa del dipendente.

## Cosa NON cambia

- Nessuna modifica database.
- Nessuna nuova tabella.
- Nessuna modifica ai repository.
- Nessuna modifica Asset Management.
- Nessuna integrazione reale Asset/Documenti ancora.

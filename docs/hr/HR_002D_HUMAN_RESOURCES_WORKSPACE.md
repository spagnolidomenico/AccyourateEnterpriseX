# HR-002D - Human Resources Workspace

## Obiettivo

Rendere visibile e utilizzabile il modulo Human Resources nella Workspace.

## Funzionalità

- Nuova voce menu `Human Resources`.
- Apertura come tab Workspace.
- Elenco dipendenti.
- Ricerca rapida.
- Filtro stato.
- KPI HR iniziali.
- Dettaglio laterale dipendente.
- Dialog Nuovo/Modifica dipendente.
- Eliminazione dipendente.
- Integrazione con `EmployeeService`.
- Validazione tramite framework HR-002C.1.
- Audit e Notification tramite `EmployeeService`.

## Cosa NON include ancora

- Tab contratti completa.
- Documenti dipendente reali.
- Asset assegnati nella scheda.
- Timeline audit visuale.
- Import/export HR.

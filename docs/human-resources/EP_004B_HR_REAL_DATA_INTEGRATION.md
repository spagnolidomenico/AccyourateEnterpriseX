# EP-004B - HR Real Data Integration

## Obiettivo

Collegare la nuova vista Human Resources Enterprise ai dati reali del database HR.

## Funzionalità

- Elenco dipendenti reale.
- Ricerca istantanea.
- Selezione dipendente.
- Entity Page aggiornata con dati reali.
- Badge stato tramite Design System v2.
- Conteggio asset collegati.
- Conteggio documenti collegati.
- Timeline base per dipendente.

## Note

Le query usano fallback sicuri: se tabelle o database non sono presenti, la vista resta utilizzabile e mostra stati vuoti.

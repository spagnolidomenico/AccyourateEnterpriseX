# Product Vision - Accyourate Enterprise X

Accyourate Enterprise X è una piattaforma ERP/MES verticale per:

- Persone
- Asset IT
- Dispositivi Medici
- Control Unit
- Capi Tessili
- Produzione
- Qualità
- Magazzino
- Lavaggi
- Assistenza
- Documentale
- Workflow e Digital Twin

## Direzione prodotto

Il sistema deve essere modulare, configurabile, auditabile, multi-azienda, multi-sede ed estendibile tramite API.

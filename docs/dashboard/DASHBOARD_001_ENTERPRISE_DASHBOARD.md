# DASHBOARD-001 - Enterprise Dashboard Foundation

## Obiettivo

Trasformare la Dashboard in un cruscotto operativo con KPI reali della piattaforma.

## KPI introdotti

- Dipendenti
- Dipendenti attivi
- Asset
- Asset assegnati
- Verbali
- Verbali PDF generati
- Documenti
- Notifiche non lette
- Eventi Audit

## Componenti

- `DashboardSnapshot`
- `DashboardKpiService`
- `EnterpriseDashboardView`

## Origine dati

I KPI vengono letti dai database locali:

- `accyourate-hr.db`
- `accyourate-assets.db`
- `accyourate-platform.db`

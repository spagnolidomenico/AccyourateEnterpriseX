# Notification Engine

## Obiettivo

Gestire notifiche centralizzate per:

- certificazioni in scadenza;
- manutenzioni programmate;
- superamento lavaggi;
- dispositivi non conformi;
- backup non eseguiti;
- produzione in ritardo.

## Fasi future

1. Tabella notifiche.
2. Regole configurabili.
3. Notifiche in dashboard.
4. Notifiche via email.
5. API notifiche.

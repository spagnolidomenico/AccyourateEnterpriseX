# ADR-0020 - Master Data Workspace Module

## Stato

Accettato

## Contesto

Dopo la fondazione database, l'Anagrafica Aziendale deve diventare visibile e navigabile nella Workspace.

## Decisione

Introdurre `MasterDataView` e `MasterDataWorkspaceModule`.

## Motivazione

- Rende utilizzabile il database Master Data.
- Prepara il collegamento con Asset Management.
- Definisce un pattern UI per moduli anagrafici futuri.

## Conseguenze

La Versione 12 dispone ora di due moduli enterprise visibili: Asset Management e Anagrafica Aziendale.

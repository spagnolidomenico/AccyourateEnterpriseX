# ADR-0004 - Workspace a schede

## Stato

Accettato

## Contesto

Accyourate usava molte finestre separate. Questo riduceva la continuità del lavoro e rendeva l'esperienza meno enterprise.

## Decisione

Introduciamo un Workspace Tab Manager per ospitare i moduli principali nella stessa finestra.

## Conseguenze

- Esperienza utente più moderna.
- Meno finestre separate.
- Navigazione più coerente.
- Base per persistenza schede, cronologia e integrazione avanzata con Command Bar.

# 07 - AI Action Engine

## Obiettivo

Permettere all'AI Assistant di eseguire azioni controllate nel gestionale.

```text
Utente
↓
AI Assistant
↓
Intent Routing Engine
↓
Action Engine
↓
Capability autorizzata
↓
Modulo applicativo
```

## Esempi azioni

- OpenModule
- SearchDevice
- OpenDigitalTwin
- FilterLowBattery
- ShowTelemetry
- ShowECG
- CreateMaintenance
- ExportPdf
- ExportExcel
- GenerateReport

# M4.1 — Adaptive Workspace

## Obiettivo
Semplificare la navigazione principale di Accyourate Enterprise X tramite macro-aree e una barra contestuale dedicata al modulo selezionato.

## Modifiche
- Sidebar primaria ridotta a otto macro-aree.
- Nuova sidebar contestuale da 220 px.
- Voci contestuali per Home, Asset, Persone, Medical, Infrastruttura, Documenti, AI e Amministrazione.
- Header esteso sopra area contestuale e workspace.
- Centro Operativo mantenuto come schermata principale.
- Release visualizzata aggiornata a M4.1.

## Verifica
```powershell
dotnet build
dotnet run --project src/Accyourate.App/Accyourate.App.csproj
powershell -ExecutionPolicy Bypass -File .\scripts\test-m4-1-adaptive-workspace.ps1
```

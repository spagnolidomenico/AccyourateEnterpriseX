# Accyourate Enterprise X 15.0.0 - Enterprise Foundation Blueprint

## Obiettivo release

La versione 15.0 consolida Accyourate Enterprise X come piattaforma enterprise stabile, coerente e pronta per moduli avanzati.

## Priorità

1. Home Enterprise moderna.
2. Workspace più coerente.
3. Ricerca globale reale.
4. Notification Center.
5. Activity Timeline.
6. UX uniforme.
7. Riduzione placeholder.
8. Stabilizzazione moduli esistenti.

# Regole di qualità

Ogni sprint deve rispettare:

- build pulita;
- smoke test superato;
- nessuna regressione su login;
- nessuna regressione su Workspace;
- nessuna regressione su Asset Management;
- nessuna regressione su Anagrafica Aziendale;
- documentazione aggiornata;
- checklist aggiornata.

---

# Criteri di completamento 15.0

La versione 15.0 sarà completa quando:

- l'utente entra in una Home Enterprise completa;
- i moduli principali si aprono come tab;
- i placeholder principali sono ridotti;
- esiste una ricerca globale iniziale;
- esiste un centro notifiche;
- esiste una timeline attività;
- la UI ha una coerenza professionale.

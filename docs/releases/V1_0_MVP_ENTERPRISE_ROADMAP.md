# Accyourate Enterprise X v1.0 - MVP Enterprise Roadmap

## Obiettivo

Realizzare una prima versione utilizzabile quotidianamente da Accyourate Group.

La v1.0 non deve essere una demo, ma una piattaforma operativa per:

- gestione persone;
- gestione asset aziendali;
- assegnazioni;
- notifiche;
- audit;
- dashboard;
- documenti di base.

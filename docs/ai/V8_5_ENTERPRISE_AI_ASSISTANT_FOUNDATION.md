# Accyourate Enterprise X - Versione 8.5 Enterprise AI Assistant Foundation

## Obiettivo

Introdurre un assistente enterprise integrato nella Workspace.

## Aggiunto

- Enterprise AI Assistant Window
- AI Assistant Engine foundation
- Classificazione intenti base
- Suggerimenti operativi
- Quick prompts
- Accesso dalla top bar della Workspace
- Accesso dalla Command Palette
- Accesso dal menu principale

## Nota

Questa è una foundation locale/regole.
Non usa ancora modelli AI esterni.
Le versioni successive potranno integrare:
- interrogazioni SQL sicure;
- ricerca documentale;
- workflow guidati;
- generazione report;
- assistente conversazionale reale.

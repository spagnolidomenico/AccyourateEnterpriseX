# Accyourate Enterprise X - Versione 9.2 AI Intent Catalog Manager

## Obiettivo

Rendere modificabile il catalogo degli intenti AI senza ricompilare il software.

## Aggiunto

- AiIntentCatalogStorage
- AI Intent Catalog Manager Window
- Salvataggio catalogo su AppData
- Ripristino catalogo default
- Modifica:
  - categoria
  - modulo Workspace
  - azione suggerita
  - parole chiave forti
  - parole chiave normali
- Accesso dal menu principale
- Accesso dalla Workspace
- Accesso dall'AI Assistant

## Percorso catalogo

Il file viene salvato in:

`%APPDATA%/AccyourateEnterpriseX/AI/intent-catalog.json`

## Nota

Da questa versione, se una frase non viene riconosciuta, puoi aggiungerla al catalogo intenti.

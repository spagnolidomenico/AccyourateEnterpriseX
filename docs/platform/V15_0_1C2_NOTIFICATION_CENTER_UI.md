# 15.0.1C.2 - Notification Center UI

## Obiettivo

Rendere visibile il Notification Engine tramite una UI integrata nella Workspace.

## Funzionalità

- Tab `Notification Center`.
- Voce `Notifiche` nella sidebar Workspace.
- Pulsante notifiche nella top bar con contatore non lette.
- Elenco notifiche.
- Filtro:
  - Tutte
  - Non lette
  - System
  - Asset
  - MasterData
  - AI
  - Security
- Pulsante `Segna tutte lette`.
- Pulsante `Segna letta` per singola notifica.

## Cosa NON cambia

- Nessuna modifica login.
- Nessuna modifica Asset Management.
- Nessuna integrazione automatica dei moduli ancora.

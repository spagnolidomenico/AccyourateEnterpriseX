# BRAND-004 - Adaptive Login Logo

## Obiettivo

Migliorare l'area logo della schermata login.

## Modifiche

- Area logo estesa orizzontalmente.
- Logo adattivo per forme quadrate o rettangolari.
- Ridimensionamento con `Stretch.Uniform`, senza deformazione.
- Fallback con iniziali azienda mantenuto.
- Rimossi i pulsanti:
  - Microsoft Account
  - Azure Active Directory

## Cosa NON cambia

- Autenticazione invariata.
- Database invariato.
- Branding Center invariato.
- Login admin/password invariato.

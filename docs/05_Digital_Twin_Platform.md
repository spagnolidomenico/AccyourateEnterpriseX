# 05 - Digital Twin Platform

## Scopo

Gestire il gemello digitale di ogni capo tessile medicale intelligente.

## Ogni Digital Twin dovrà includere

- codice dispositivo
- serial number
- QR Code
- RFID/NFC
- cliente/paziente assegnato
- stato operativo
- batteria
- firmware
- sensori
- ECG
- battito cardiaco
- qualità segnale
- storico eventi
- manutenzioni
- sanificazioni
- documentazione
- certificazioni

## Funzioni future

- ECG Viewer
- grafica del corpetto
- posizione sensori
- alert clinici
- telemetria reale
- export PDF
- report manutenzione

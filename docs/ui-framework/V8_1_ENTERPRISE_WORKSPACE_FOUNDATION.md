# Accyourate Enterprise X - Versione 8.1 Enterprise Workspace Foundation

## Obiettivo

Iniziare il passaggio da molte finestre isolate a un'unica shell enterprise con area centrale dinamica.

## Aggiunto

- Enterprise Workspace
- Area contenuti centrale
- Navigation State
- WorkspaceModuleFactory
- Moduli caricati nel contenitore centrale
- Command Palette foundation
- Status bar
- Sidebar e top bar permanenti

## Moduli interni iniziali

- Workspace Home
- Dashboard summary
- Analytics summary
- Branding summary
- Design System summary
- Enterprise Architecture summary

## Nota

Alcuni moduli restano ancora finestre esterne per non perdere stabilità. Verranno migrati progressivamente.

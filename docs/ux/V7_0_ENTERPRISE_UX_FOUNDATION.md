# Accyourate Enterprise X - Versione 7.0 Enterprise UX Foundation

## Obiettivo

Portare l'interfaccia verso un'esperienza enterprise moderna.

## Aggiunto

- Enterprise UX Center
- Top Bar Preview
- Accesso rapido a:
  - Ricerca globale
  - Notifiche
  - Tema
  - Impostazioni
  - Utente
- Base per:
  - preferiti
  - recenti
  - ricerca nel menu
  - temi live
  - dashboard personalizzabile

## Nota

La top bar è introdotta come anteprima separata per evitare regressioni sulla finestra principale.
L'integrazione diretta nella finestra principale sarà consolidata nella 7.1.

# Standard UX - Accyourate Enterprise X

## Regole generali

- Ogni modulo deve avere un titolo chiaro.
- Ogni modulo deve avere filtri e azioni standard.
- I colori devono usare il tema centralizzato.
- Le azioni principali devono usare il colore primario.
- Le azioni secondarie devono usare pulsanti neutri.
- Le griglie devono avere intestazioni coerenti.
- Le finestre devono usare card bianche su sfondo chiaro.

## Azioni standard

- Nuovo
- Modifica
- Archivia/Ripristina
- Esporta
- Apri dettaglio
- Timeline/Digital Twin
- Stampa/Genera documento

## Obiettivo

Ridurre finestre incoerenti e preparare la futura interfaccia integrata a schede.

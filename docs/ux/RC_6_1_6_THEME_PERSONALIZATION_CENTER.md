# Accyourate Enterprise X - RC 6.1.6 Theme & Personalization Center

## Obiettivo

Aggiungere un modulo per personalizzare l'identità visiva del gestionale.

## Aggiunto

- Nome azienda
- Tema: Chiaro / Scuro / Sistema
- Colore primario
- Colore menu laterale
- Colore area lavoro
- Stile menu
- Percorso logo
- Anteprima tema
- Salvataggio preferenze in `app_settings`
- Audit `THEME_PREFERENCES_UPDATED`

## Nota

In questa release le preferenze vengono salvate e mostrate in anteprima.
L'applicazione completa del tema a tutta l'interfaccia sarà progressiva nelle release successive.

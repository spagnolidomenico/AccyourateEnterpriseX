# Accyourate Enterprise X - RC 6.1.5 Collapsible Enterprise Menu

## Obiettivo

Rendere il menu laterale più ordinato e più intuitivo.

## Aggiunto

- Sezioni menu espandibili/collassabili.
- Tutte le sezioni chiuse all'avvio.
- Indicatori `▶` e `▼`.
- Voci organizzate per area:
  - Centro Operativo
  - Moduli Base
  - Medical Suite
  - Logistica
  - Assistenza
  - Documentale
  - Amministrazione

## Test

1. Avviare il gestionale.
2. Verificare che le sezioni siano chiuse.
3. Espandere ogni sezione.
4. Aprire i moduli principali.
5. Verificare che il menu continui a scorrere.

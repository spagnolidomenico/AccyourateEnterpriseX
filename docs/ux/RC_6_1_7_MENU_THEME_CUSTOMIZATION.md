# Accyourate Enterprise X - RC 6.1.7 Menu Theme Customization

## Aggiunto

Nel modulo Personalizzazione Tema ora sono configurabili anche:

- colore voce menu normale;
- colore testo voce menu;
- colore voce al passaggio del mouse;
- colore testo hover;
- colore voce selezionata;
- colore testo selezionato.

## Nota

La release salva le preferenze in database e aggiorna l'anteprima.
L'applicazione completa del tema al menu reale sarà consolidata nella prossima release.

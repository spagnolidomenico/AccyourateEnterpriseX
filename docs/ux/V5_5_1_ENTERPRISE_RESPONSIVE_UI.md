# Accyourate Enterprise X - Versione 5.5.1 Enterprise Responsive UI

## Obiettivo

Correggere il problema delle finestre che, se non abbastanza grandi, nascondono campi e pulsanti.

## Interventi

- Standard `ResponsiveUi`
- Dimensioni minime più sicure
- Scroll verticale e orizzontale automatico
- Card con margini coerenti
- Documentazione standard responsive

## Regola UX

Ogni nuova finestra deve:

- avere MinWidth e MinHeight;
- contenere il contenuto principale in ScrollViewer;
- evitare pulsanti fuori area visibile;
- usare card e stack con spaziature coerenti.

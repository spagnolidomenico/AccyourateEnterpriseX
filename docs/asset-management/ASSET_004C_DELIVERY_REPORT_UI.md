# ASSET-004C - Delivery Report UI

## Obiettivo

Rendere visibile e utilizzabile la gestione dei verbali di consegna nella Workspace.

## Funzionalità

- Nuovo modulo Workspace `Verbali consegna`.
- Lista verbali.
- Ricerca per numero, dipendente, asset.
- Filtro per stato.
- Dettaglio laterale.
- Generazione PDF da UI.
- Apertura PDF.
- Apertura cartella PDF.

## Output PDF

I PDF vengono salvati in:

```text
Documenti/Accyourate Enterprise X/Verbali Consegna
```

## Cosa NON include ancora

- Creazione manuale di verbali da UI.
- Eliminazione verbali.
- Firma digitale.
- Stampa diretta gestita internamente.

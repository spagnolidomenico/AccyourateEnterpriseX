# M7.7.2 — PDF Readability Fix

## Correzioni

- testo dello stato sempre scuro e leggibile;
- colore aziendale usato come indicatore laterale, non come colore del testo;
- separatori centrati nello spazio tra le righe;
- maggiore altezza minima delle righe etichetta/valore;
- nessuna linea sovrapposta alle etichette o ai valori.

## Verifica

Rigenera un verbale dal Registro Consegne e controlla le sezioni:

- Numero verbale;
- Data emissione;
- Stato;
- Nominativo;
- Asset principale.
